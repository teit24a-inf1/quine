# Quines

Ein *Quine* ist ein Programm, das seinen eigenen Quelltext ausgibt.

Um einen Quine zu schreiben, gibt es unterschiedlich komplizierte Ansätze.
Ein "echter" Quine gibt seinen Quelltext aus, **ohne** dabei auf die Quelldatei
zuzugreifen.

Schreiben Sie einen solchen echten Quine im Verzeichnis `quine`.
D.h erweitern/ändern Sie das vorgegebene Programm, so dass es exakt seinen eigenen
Quelltext auf die Konsole schreibt.
